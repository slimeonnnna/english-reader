# 📖 英语点读助手 (English Reader)

纯本地运行、零外部 API、无网络依赖的桌面级英语点读软件。

---

## ✨ 核心特性

1. **零 API、完全免费、隐私安全**
   - 不依赖任何第三方收费或限制频率的翻译/语音 API。
   - 数据完全保留在您的电脑本地，无需联网也能全功能使用。

2. **点读翻译 (点哪个词就翻译哪个词)**
   - 鼠标点击文章中任意单词，立即弹出精美浮动卡片。
   - 显示**国际音标 (IPA)**、**词性**与**准确中文释义**。
   - **智能词形还原引擎 (Lemmatizer)**：自动识别并推导过去式（`-ed`）、进行时（`-ing`）、复数形式（`-s/-es`）、比较级（`-er/-est`）、不规则变化（如 `went -> go`, `children -> child`, `better -> good` 等）。

3. **系统级真人语音朗读**
   - 基于 HTML5 Web Speech API，直接调度 Windows 系统自带的高品质英语发音引擎（如 Microsoft David, Zira, Mark, 或 Edge 自然发音）。
   - **点词即读**：点击单词即刻听到标准发音。
   - **单句点读**：可一键朗读单词所在的完整例句。
   - **整篇连续朗读**：支持一键全文朗读，当前朗读句子自动黄色高亮，并平滑居中滚动（跟读卡拉OK模式）。
   - **语速调节**：支持 0.75x 慢速、1.0x 正常、1.25x / 1.5x 变速。

4. **本地生词本 (支持导出 Anki / Excel)**
   - 点击卡片中的 ⭐ 图标，即可将生词、音标、释义及原文例句一键存入生词本。
   - 数据通过浏览器的本地存储永久保存。
   - 支持一键导出为 **CSV 格式** (可在 Excel 中打开) 或 **Anki 卡片格式** (导入 Anki 背单词)。

5. **支持任意文章输入与导入**
   - 随时粘贴任意英文长文、演讲稿、学术论文、新闻或小说章节。
   - 支持点击“导入本地 TXT”直接载入本地英语文本文件。
   - 内置乔布斯斯坦福演讲、《小王子》经典文学节选、AI 前沿科技文章等示例。

6. **护眼与排版自适应**
   - 提供 4 套排版主题：**纯白简约**、**暖黄羊皮纸**、**豆沙绿护眼**、**夜间深色模式**。
   - 字体与字号调节：支持经典衬线体 (Serif)、现代无衬线 (Sans) 及 14px~28px 字号滑块。

## 🚀 启动方式

直接双击运行本目录下的：
👉 **`启动英语点读软件.bat`**

或者直接用 Edge、Chrome、Firefox 等任意现代浏览器打开：
👉 **`index.html`**
